## 公网分享与待验收项

官方 cloudflared 已下载并通过 SHA-256 校验，临时隧道能够注册到 Cloudflare，后端就绪检查正常；后续运行中也已观察到公网请求成功到达首页及 API。当前网络对新生成的 `*.trycloudflare.com` 地址存在间歇性 DNS 延迟，曾出现电脑或 iPhone 暂时提示找不到服务器、稍后又能解析的情况。启动脚本现会等待公网检查；若本机 DNS 失败但隧道已经注册，则保留服务并显示地址，避免自动关闭仍可从其他网络访问的隧道。

现场应保持启动终端运行，并在二维码展示前用手机流量和现场 Wi-Fi 各打开一次最新地址。临时地址随重启变化且不保证稳定；需要稳定入口时使用已有固定 HTTPS 反向代理和 `STORYBRIDGE_PUBLIC_URL`。Android、iPhone 微信的完整生成流程以及至少 3 位新用户无指导体验尚未完成，记录表见 [分享说明](SHARING.md#验收与现场记录)。手机模拟测试与公网请求记录不能替代这些现场验收。
